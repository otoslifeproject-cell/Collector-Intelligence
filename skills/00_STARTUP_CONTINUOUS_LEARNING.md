# 00 — STARTUP CONTINUOUS LEARNING (MANDATORY)

**Trigger:** Run at the very start of **every conversation** in the Collector Intelligence Project. The governing Project Instructions explicitly mandate this skill. Run before selecting any other specialist skill. Re-run the relevant checks at the start of a materially new object or workflow within a long chat.

## Preflight — before making substantive claims
- Read/apply the controlling Master Brief v4.0, Source & Evidence Policy v4.0, active Project Instructions v4.1, benchmark learnings and this startup skill when available. Do not misrepresent availability.
- Recognise the requested workflow and load the matching skills (Quick Buy, identification, comp research, photo examination, archive ingestion, sell, catalogue, technical build).
- Establish object/image boundaries; retain user observations as observations, with 0–100 attribution/valuation confidence separately.
- Search existing reviewed Knowledge Brain records and relevant private Drive research where connected and authorised; check corrections, original sources, claimed sold vs unsold lots, and freshness. If tools unavailable, work provisionally and identify the gap.
- Keep **Drive = original/unverified source archive**; **Supabase = controlled versioned structural intelligence and reviewed findings**; **GitHub = source code/governance**.
- Enforce evidence grades, reproducible citations, strict genuine sold-price provenance, and conservative net-return decisioning.
- End the workflow with a source-linked save/write-back checklist. Never claim files were saved until an actual Drive file ID or Supabase ID and read-back are verified.
- Never overwrite original research or discard rejected hypotheses; capture test failures as regression learnings.
- Do not execute expensive gateway tests simply for preflight. Preserve privacy and owner permissions.

## Startup pass/fail log (internal)
Record internally: active source revisions; object/session identity; relevant prior knowledge retrieved or unavailable; workflow skills activated; unresolved source conflicts. At completion record actual save locations and unverified items.

**Acceptance:** A message merely saying "I checked the knowledge" does not meet the skill. Internal retrieval and output write-back must be tested and source-linked when available.
