# Skill 15 — Canonical Continuity, Migration and Source-Trust Gate

This skill is SUBORDINATE to `02_MASTER_PROJECT_BRIEF.md` (product) and `03_SOURCE_AND_EVIDENCE_POLICY.md` (evidence). It is not permission to overwrite those sources.

## Invoke
On every substantive feature build, new research workflow, source import, schema change, valuation release, or context handover.

## Mandatory start gate
1. Identify the correct Supabase project (`bwdafrwkimjvwfoqomot`), current GitHub branch/commit and applicable Vercel deployment.
2. Read the latest FULL canonical documents from the owner-scoped `canonical_documents` archive, not an assistant recollection or a cropped source excerpt.
3. Capture each document key + SHA-256. Master Brief supersedes any contradictory operational instructions.
4. Read `docs/CURRENT_HANDOVER.md`, `docs/PROJECT_PROGRESS_LOG.md`, `docs/RECOVERY_MANIFEST_2026-10-10.md` and pending improvement queue. Treat historical test outputs as observations only.

## Evidence trust gate
Separate these independent axes:
- Design/maker attribution source authority: primary maker archive / museum documented example > sourced specialist publication > auction/dealer description > marketplace/visual AI hypothesis.
- Market price authority: verified relevant realised/hammer results > genuinely sold/indexed completed sales > dealer asking context > marketplace asking context.
- Object-to-reference comparability: pattern, maker certainty, form, construction, size, colour, mark, condition, recency and venue. The canonical 100-point comparable score is a matching aid, not a truth certificate.

Never promote a source by website reputation alone. Capture exact original claim, URL, page/lot/record ID, issuer, check date, provenance, corroboration and contradiction. A VERIFIED_DIRECT label generated by a model remains an assertion until the source is independently checked and the check is logged.

## Valuation safeguard
No high-confidence pricing from active asks, visually similar but unverified attributions, or a single exceptional sale. Maintain auction hammer vs premium-inclusive total vs marketplace sold vs estimate vs dealer ask vs marketplace ask. Price range must disclose fees, currency, size/condition and confidence; insufficient sold data implies PROVISIONAL, research/specialist route.

## Migration and data recovery gate
- Archive original byte-for-byte material with source hash and immutable version history; do not replace a previous version on failed extraction.
- Reject short/error-placeholder content before it can become authoritative.
- Never invent lost prior conversations, lot receipts, record links or original image evidence.
- Preserve unmatched uploads and unapproved drafts as separate categories; never create permanent item IDs without owner approval.
- Repeat count and hash verification after writing.
- Security: JWT owner scoping and RLS required; canonical docs readable but not modifiable by ordinary clients, private images via signed URLs.
- Keep GitHub and Supabase in sync with **explicit publication**; neither updates the other automatically.
- Keep a portable backup outside Supabase.

## Completion report
Record: changed files and commits, migration names, database counts/hash checks, actual Vercel status, regression result, known gaps, unresolved security advisor warnings and next gated test. Mark untested as UNVERIFIED. Never claim a paid AI result, direct sale, authenticated UI pass or perfect security without evidence.

## User retest gate
Do not ask for another 12-photo Holmegaard test until deployment passes, canonical policy retrieval works in an authenticated request, the second-pass status is visible, original image indices are preserved, and source trust reporting is saved in the analysis run.
