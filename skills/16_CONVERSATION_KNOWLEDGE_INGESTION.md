# Skill 16 — Conversation-to-Knowledge Ingestion and Learning Regression

Subordinate to Master Brief and Source & Evidence Policy. Invoke for every historical chat import and every completed new item analysis.

1. **Capture without reconstruction:** retain the original PDF/TXT/HTML/chat export, its checksum and original page/message numbering. Do not claim automatically to access sibling chat windows.
2. **Segment by object and decision:** assign provisional subject IDs, group images without guessing, extract each distinct claim, competing attribution, correction, documentary link, comp and sale outcome. Record page/line anchors to original transcript.
3. **Evidence classify:** FACT = directly observed in the supplied record, not a true maker claim; POSSIBLE/STRONG = interpretations; VERIFIED_DIRECT requires independent source inspection. Record who asserted it (user/model/original source), whether source was actually accessed and date. Old model valuation ranges are NOT realised comps.
4. **Preserve revisions:** link chronological hypotheses and correction reason. Do not overwrite early misidentifications; retain them as negative teaching examples.
5. **Dedup:** compute original transcript SHA-256 and normalized assertion key; cross-reference, not discard, distinct versions. Distinguish identical uploads from independently corroborated sources.
6. **Write-back:** original transcript to secure source archive, extracted claim ledger to Knowledge Brain, specific item evidence only with safe immutable object identity, actual comps only when direct original sale data exists. Mark source freshness.
7. **Retrieval regression:** show the saved record can be found by category, maker, feature, signature and failure mode. Test at least a positive and misleading match; reject an asking-price-as-sold example.
8. **Completion metrics:** source conversations received / preserved / extracted / checked; claims by trust tier; unmatched photographs; verified realisations; items with revisions; closed sale outcomes; current backlog. Log what was committed, actually stored, queried and tested.
9. **Security:** avoid public Drive links, addresses/contact details in public repos, passwords or tokens. Owner-protected access, hashed/dated versions, independent backup. If Drive connector lacks raw-file upload, produce an export and say so.
10. **Non-drift:** never revise Master Brief based solely on a model output. Record proposed changes for review with regression evidence before promotion.

MASTER exemplar: a six-inch cut crystal vase was initially described as mid/late 20th century, then changed to possible c.1890–1920/American Brilliant after user feedback about sharp deep cuts, brilliant refraction and 500g weight. Those observations are evidence leads, not conclusive proof of American manufacture or period. Save ALL attribution states and caution against treating weight and dispersion as proof of age.
