# Collector Intelligence — Project Branding Instruction Addendum v1
Approved 2026-10-14 by project owner. Applies to visual identity, UX writing and branded outputs only.
Subordinate to 02_MASTER_PROJECT_BRIEF.md (product) and 03_SOURCE_AND_EVIDENCE_POLICY.md (research). Do not weaken either.

## Description
Collector Intelligence is a premium, evidence-led AI technology platform for collectible identification, research, valuation, collection management and intelligent selling decisions, beginning with glass and crystal.

## Brand instruction
Use **Concept C — The Collector's Facet**, precisely as approved in docs/APPROVED_BRAND_IDENTITY_V1.md and the original reference board (SHA-256 6157a76e6d92036776d5febc9ba714d7cc00848b26e51be42c45fbc57d979538).
Brand values: trust, accuracy, detail, verification, intelligence, discovery.
Product voice: authoritative, precise, concise, evidence-led, confident only where proof warrants it.
Core brand statement: "Advanced intelligence. Verified evidence. Confident decisions."
Palette: graphite #0B0F14, amber #C9A96B, off-white #F7F5EF, stone grey #D6D6D1, cool grey #8A9099.
Preferred typography direction: Inter / Plus Jakarta Sans subject to font licensing.
Maintain headline-first, two-click journeys with expandable provenance and extended details.
Never mistake brand claims or illustrative mockups for verified item records.
For final production identity install only genuine approved graphic assets (not an unreviewed reconstruction of a presentation-board screenshot).
Preserve previous branding and development revisions and log deployment acceptance.

## Mandatory acceptance
- Logo identical across sidebar/login/favicon/dashboard/exports, with full colour and monochrome.
- Accessibility, small-screen, dark/light contrast and typography rights verified.
- All trust gates remain unchanged; provisional findings and AI-suggested sold prices are not independently verified.
- Document exact GitHub commit, Vercel result, evidence preservation and unresolved limitations.
