## Implemented recovery

`/uploads` lists the actual owner's committed single/batch uploads, including DRAFT and APPROVED records, in exact-count pages of 20 with stable created_at/id order. Older uploads can be reached instead of relying on the former recent-twelve/six-card research view. Page length, count, duplicate identity and owner/mode/status metadata are checked; unavailable or inconsistent history becomes an explicit error rather than an empty list. A fresh account's genuine empty list is distinguished from failed reads.

`/uploads/:id` is a bookmarkable, read-only saved-session reader. It survives refresh for committed sessions and preserves full original saved JSON, including long malformed/error AI responses, as escaped text behind optional details. It shows stored stage, model and source-photo metadata without treating persistence as attribution or sold-price verification. Checking performs actual Auth/owned reads and fresh private signing only: no paid API dispatch, new staged row, approval or other REST mutation. A later independently completed session can be checked and opened in the established SavedDraft workflow. Render-unsafe output remains raw; retained first pass can open review but catalogue approval stays blocked.

Previews use only explicit paths from a complete, unique, ordered own manifest. Foreign paths, missing originals, duplicate paths, traversal/control/encoded path forms and inconsistent counts cannot mint previews. Legacy uploads used a folder UUID different from their analysis UUID; the reader retains their actual folder instead of inventing a path from the row ID. Photo signing is owner-scoped, time-limited and read-only. Denied links can be refreshed without losing the original response.

The reader reuses existing photo-tile/caption/theme styles, contains the original aspect ratio and gives a visible image-failure fallback. Preview completion is reflected in aria-busy. Actual source files and saved results remain unchanged. Account/route lifetime guards after awaits prevent late previous responses from entering the current private view. AI Intake links to all saved uploads and the held saved session; Research has an always-available All saved uploads link. No dependency, global CSS, API handler, schema, migration, proposal or live permission change.
