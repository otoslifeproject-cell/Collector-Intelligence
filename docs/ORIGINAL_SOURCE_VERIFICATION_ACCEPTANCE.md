# Original-source verification acceptance

An owner review alone is not an independently verified auction result. Require a source URL, retrieval timestamp, original lot reference, archived snapshot identifier and SHA-256, result classification, price/currency/premium basis, and an explicit source-verification decision. Deny automatic VERIFIED_DIRECT on snippets, dealer asking prices, missing source pages, unsold lots or unverifiable results. Retain conflicting evidence and chronological revisions. Run tests before enabling automated promotion. STATUS: specification only; not deployed.
